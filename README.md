# 📱 PWA QR Code Reader

スマートフォン（Android / iOS）のブラウザで軽快に動作する、インストール可能なPWA仕様のQRコードリーダーです。  
GitHub Pages などの静的Webホスティング環境でそのまま動かすことができます。

---

## ✨ 主な機能

- 📷 **カメラ自動選択・記憶**: 最後に使用したカメラ（背面カメラなど）をブラウザ（`localStorage`）に記憶。
- 🔍 **ズーム設定の維持**: 変更したズーム倍率を次回起動時や再スキャン時にも自動で復元。
- 📋 **自動クリップボードコピー**: QRコードを読み取った瞬間、自動でテキストをコピー（通知トースト表示付き）。
- 🔗 **コンテキスト対応アクション**:
  - **URL**: 「ブラウザで開く」ボタンを表示
  - **メールアドレス**: 「メールを送信する」ボタンを表示
  - **その他プレーンテキスト**: コピーのみ実行
- 📲 **PWA対応**: ホーム画面に追加してスタンドアロンアプリ（全画面表示）として使用可能。
- 🔒 **プライバシー配慮**: スキャン履歴などはサーバー・端末に保存されず、完全ローカルで完結。

---

## 🚀 使い方

1. アプリのURLにアクセスし、カメラの使用を許可します。
2. 必要に応じてカメラの切り替えやズーム倍率を調整します。
3. QRコードをカメラにかざすと、自動で読み取りが行われます。
4. 結果が画面に表示され、テキストがクリップボードにコピーされます。

---

## 🛠️ 開発・技術スタック

- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+)
- **QRスキャンライブラリ**: [html5-qrcode](https://github.com/mebjas/html5-qrcode) (v2.3.8)
- **PWA**: Service Worker (`sw.js`), Web App Manifest (`manifest.json`)
- **データ保持**: Web Storage API (`localStorage`)
